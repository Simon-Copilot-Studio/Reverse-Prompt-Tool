# Reverse-Prompt-Tool
reverse-prompt-tool
🚀 REVERSE-PROMPT // 未來感逆向工程儀表板

「解構、重組、復刻成功。」

本專案是一個專為 AI 提示工程師（Prompt Engineers）設計的高級分析工具。透過逆向工程（Reverse Engineering）的思維，協助使用者將任何卓越的文字、圖像或策略樣本，轉化為可重複執行的結構化 AI 指令集（Prompt）。

🌟 核心願景

在 AI 時代，最珍貴的資產不是內容本身，而是產生內容的「思考邏輯」。本工具旨在：

提取隱性知識：將高手作品中的內隱知識（Tacit Knowledge）顯性化。

建立標準算法：將感性的創作轉化為理性的規則。

加速 AI 協作：讓 AI 能夠精確模仿並超越現有的成功範例。

✨ 功能亮點

1. 模組化引擎 (Engine Modules)

預設 9 種主流商務與創作場景，一鍵生成精準的分析指令：

📱 社群動態：分析注意力分配與情緒鉤子。

✉️ 商務開發：解構信任建立與行動邀請（CTA）。

🎨 視覺指令：提取光影參數與構圖邏輯。

...以及客服、會議、提案、策略等全方位支援。

2. 未來感 UI 設計

深色模式 (Obsidian Theme)：降低長時間工作的視覺疲勞。

玻璃擬態 (Glassmorphism)：使用 CSS backdrop-filter 打造半透明層次感。

霓虹動效：動態漸變邊框與呼吸燈效果，提升沉浸式體驗。

3. 極致的響應式體驗 (RWD)

針對手機、平板、電腦進行多維度優化。

支援 iOS/Android 觸控操作優化，無彈跳延遲。

🛠️ 技術架構

本專案採用 Single-File Application (SFA) 架構，確保輕量與高度可移植性：

核心語言: HTML5, JavaScript (Vanilla JS)

樣式框架: Tailwind CSS (CDN Version)

字體資源: Google Fonts (Inter, Space Mono)

視覺元素: CSS3 Gradients, Backdrop Filters, Canvas-based Grid System

🚀 部署指南 (GitHub Pages)

由於本專案為純靜態頁面，部署極為簡單：

Fork 本儲存庫。

重命名檔案：將 universal_reverse_prompt_app.html 改名為 index.html。

開啟 GitHub Pages：

前往 Settings > Pages。

分支選擇 main，資料夾選擇 / (root)。

點擊 Save。

即刻訪問：您的專屬工具將在 https://<username>.github.io/<repo-name>/ 上線。

📝 指令邏輯說明

產出的指令遵循 Google 提示工程策略，包含以下結構：

角色定義 (Role)：設定資深架構分析師身份。

意圖識別 (Intent)：核心痛點與受眾分析。

規則抽象化 (Rules-as-Code)：區分硬性框架與內容素材。

負面排除 (Negative Constraints)：避免平庸的路徑。

🎨 自定義修改

如果您想修改視覺風格，可以在原始碼中搜尋 :root 變數：

:root {
    --obsidian: #05070a;      /* 背景深色 */
    --neon-indigo: #6366f1;   /* 主題紫色 */
    --neon-cyan: #22d3ee;     /* 主題青色 */
}
